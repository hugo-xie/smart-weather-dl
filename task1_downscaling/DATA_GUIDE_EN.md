# Task 1 Data Guide - Meteorological Data Downscaling

## Dataset: ERA5 Reanalysis Data

**Source**: ECMWF (European Centre for Medium-Range Weather Forecasts)  
**Website**: https://cds.climate.copernicus.eu/  
**License**: Free and open after registration

### Data Characteristics

| Attribute | Low-Resolution Input | High-Resolution Target |
|------|------------|------------|
| Spatial resolution | 1.0 degree x 1.0 degree, about 100 km | 0.25 degree x 0.25 degree, about 25 km |
| Temporal resolution | 6 hours | 6 hours |
| Variable | 2m temperature (t2m) | 2m temperature (t2m) |
| Region | China region, 70E-140E and 15N-55N | Same as input |
| Time range | 2010-2020 | 2010-2020 |

## Step 3: Download ERA5 Data

```python
import cdsapi

c = cdsapi.Client()

for year in range(2010, 2021):
    c.retrieve(
        'reanalysis-era5-single-levels',
        {
            'product_type': 'reanalysis',
            'variable': '2m_temperature',
            'year': str(year),
            'month': [f'{m:02d}' for m in range(1, 13)],
            'day': [f'{d:02d}' for d in range(1, 32)],
            'time': ['00:00', '06:00', '12:00', '18:00'],
            'area': [55, 70, 15, 140],
            'grid': [0.25, 0.25],
            'format': 'netcdf',
        },
        f'era5_t2m_025deg_{year}.nc'
    )
```

> **Note**: The full download usually takes about 2-4 hours, and the file size is about 50-100 GB for the full data range.  
> It is recommended to download one year first, about 5-10 GB, for testing.

## Step 4: Run the Preprocessing Script

After downloading, the yearly NetCDF files should be placed under `task1_downscaling/` with the following naming pattern:

```text
era5_t2m_025deg_2010.nc
era5_t2m_025deg_2011.nc
...
era5_t2m_025deg_2020.nc
```

Run from the project root:

```bash
python task1_downscaling/download_data.py
```

Or enter the task directory and run:

```bash
cd task1_downscaling
python download_data.py
```

The script performs the following processing steps:

1. Read the yearly ERA5 NetCDF files from `2010-2020`.
2. Read variable `t2m`, with automatic support for either `time` or `valid_time` as the time dimension name.
3. Crop the original high-resolution grid to a size divisible by `4`.
4. Generate LR data from HR data using `4x4` block mean pooling.
5. Compute the normalization mean and standard deviation only from the training years, `2010-2017`.
6. Normalize LR and HR data in train/val/test using the same training-set mean and standard deviation.
7. Save the results as `.npy` files and write `metadata.json`.

The current spatial sizes are:

| Data | Original Size | Preprocessed Size | Description |
|------|---------|-------------|------|
| HR | `161 x 281` | `160 x 280` | Drops the last latitude row and last longitude column so the size is divisible by 4 |
| LR | - | `40 x 70` | Generated by averaging each `4x4` HR block |

Default output directory:

```text
task1_downscaling/processed_era5_t2m_downscaling/
```

If complete preprocessed data already exists, the script will reuse it directly. To force regeneration, use:

```bash
python task1_downscaling/download_data.py --overwrite
```

Common arguments:

| Argument | Default | Description |
|------|--------|------|
| `--raw-dir` | `task1_downscaling/` | Directory containing the raw yearly `.nc` files |
| `--output-dir` | `task1_downscaling/processed_era5_t2m_downscaling/` | Preprocessed output directory |
| `--variable` | `t2m` | Variable name to read from NetCDF |
| `--scale-factor` | `4` | Downscaling factor |
| `--chunk-size` | `64` | Number of time steps to read per chunk; reduce it if memory is tight |
| `--overwrite` | Disabled | Regenerate existing preprocessed data |
| `--download` | Disabled | Download with the CDS API first, then preprocess |

## Step 5: Preprocessed Output Files

After preprocessing, the output directory has the following structure:

```text
processed_era5_t2m_downscaling/
├── metadata.json
├── train_lr.npy
├── train_hr.npy
├── train_time.npy
├── val_lr.npy
├── val_hr.npy
├── val_time.npy
├── test_lr.npy
├── test_hr.npy
├── test_time.npy
├── latitude_hr.npy
├── longitude_hr.npy
├── latitude_lr.npy
└── longitude_lr.npy
```

Core training files:

| File | Shape | Description |
|------|-------|------|
| `train_lr.npy` | `(11688, 40, 70)` | Low-resolution training input |
| `train_hr.npy` | `(11688, 160, 280)` | High-resolution training target |
| `val_lr.npy` | `(2920, 40, 70)` | Low-resolution validation input |
| `val_hr.npy` | `(2920, 160, 280)` | High-resolution validation target |
| `test_lr.npy` | `(1464, 40, 70)` | Low-resolution test input |
| `test_hr.npy` | `(1464, 160, 280)` | High-resolution test target |

Auxiliary files:

| File | Description |
|------|------|
| `metadata.json` | Stores split years, sample counts, spatial shapes, normalization mean, and normalization standard deviation |
| `*_time.npy` | ERA5 timestamp for each sample |
| `latitude_hr.npy`, `longitude_hr.npy` | Real latitude and longitude coordinates for each HR grid row/column |
| `latitude_lr.npy`, `longitude_lr.npy` | Real latitude and longitude coordinates for each LR grid row/column |

Default year split:

| Split | Time Range | Samples, 6-hour interval |
|------|----------|--------------------|
| Train | `2010-2017` | `11688` |
| Validation | `2018-2019` | `2920` |
| Test | `2020` | `1464` |

The normalization statistics are computed from the training HR data. The current preprocessed result is:

```text

std  = 15.738599515322958 K
```

## Step 6: PyTorch Dataset and DataLoader

`download_data.py` already provides `ERA5DownscalingDataset` and `build_dataloaders()`, so there is no need to manually replace synthetic data in the model file.

Use the Dataset directly:

```python
from task1_downscaling.download_data import ERA5DownscalingDataset

train_set = ERA5DownscalingDataset(split="train")
lr, hr = train_set[0]

print(lr.shape)  # torch.Size([1, 40, 70])
print(hr.shape)  # torch.Size([1, 160, 280])
```

Build train/val/test DataLoaders together:

```python
from task1_downscaling.download_data import build_dataloaders

train_loader, val_loader, test_loader = build_dataloaders(
    batch_size=4,
    num_workers=0,
)

for lr_batch, hr_batch in train_loader:
    print(lr_batch.shape)  # (B, 1, 40, 70)
    print(hr_batch.shape)  # (B, 1, 160, 280)
    break
```

The Dataset uses `np.load(..., mmap_mode="r")` by default when reading `.npy` files, so it does not load all data into memory at once. `__getitem__` converts each sample to `torch.FloatTensor` and automatically adds the channel dimension:

```text
LR: (H_lr, W_lr) -> (1, H_lr, W_lr)
HR: (H_hr, W_hr) -> (1, H_hr, W_hr)
```

If you also need the timestamp:

```python
test_set = ERA5DownscalingDataset(split="test", return_time=True)
lr, hr, time = test_set[0]
print(time)
```

## Step 7: Run the CNN Downscaling Model

`downscaling_cnn.py` is already connected to the real ERA5 data. Run it directly:

```bash
python task1_downscaling/downscaling_cnn.py
```

At startup, the script checks the data state:

1. If `processed_era5_t2m_downscaling/` exists, it reads the preprocessed data directly.
2. If the preprocessed directory does not exist, it automatically calls `preprocess_era5()` to generate data from the yearly `.nc` files.
3. It trains on the train split, validates on the val split, and performs final evaluation on the test split.
4. It saves the best validation model to `best_downscaling_cnn.pth`.

You can adjust the training scale through environment variables:

```bash
DOWNSCALING_BATCH_SIZE=4 \
DOWNSCALING_EPOCHS=50 \
DOWNSCALING_NUM_WORKERS=0 \
python task1_downscaling/downscaling_cnn.py
```

For quick debugging, limit the number of samples used by each split:

```bash
DOWNSCALING_EPOCHS=1 \
DOWNSCALING_MAX_SAMPLES=8 \
DOWNSCALING_BATCH_SIZE=2 \
python task1_downscaling/downscaling_cnn.py
```

Available environment variables:

| Environment Variable | Default | Description |
|----------|--------|------|
| `DOWNSCALING_BATCH_SIZE` | `4` | Batch size |
| `DOWNSCALING_EPOCHS` | `50` | Number of training epochs |
| `DOWNSCALING_NUM_WORKERS` | `0` | Number of DataLoader workers |
| `DOWNSCALING_MAX_SAMPLES` | `0` | Debug option; when greater than 0, each split uses at most this many samples |
| `DOWNSCALING_RAW_DIR` | `task1_downscaling/` | Raw `.nc` data directory |
| `DOWNSCALING_DATA_DIR` | `processed_era5_t2m_downscaling/` | Preprocessed data directory |

## Step 8: Denormalization and Geographic Coordinates

The model is trained on standardized temperature values:

```text
normalized = (temperature_K - mean) / std
```

For evaluation or saving predictions, denormalize back to Kelvin:

```python
import json
import numpy as np
from pathlib import Path

data_dir = Path("task1_downscaling/processed_era5_t2m_downscaling")
metadata = json.loads((data_dir / "metadata.json").read_text(encoding="utf-8"))

mean = metadata["normalization"]["mean"]
std = metadata["normalization"]["std"]

pred_k = pred_norm * std + mean
target_k = target_norm * std + mean
```

Save a 2D prediction as NetCDF with latitude/longitude coordinates:

```python
import numpy as np
import xarray as xr

lat = np.load(data_dir / "latitude_hr.npy")
lon = np.load(data_dir / "longitude_hr.npy")

da = xr.DataArray(
    pred_k,
    dims=("latitude", "longitude"),
    coords={"latitude": lat, "longitude": lon},
    name="t2m_downscaled",
)
da.to_netcdf("predicted_t2m_sample.nc")
```

## Evaluation Metrics

| Metric | Description | Good Reference Value |
|------|------|------------|
| **RMSE** | Root mean squared error, in K | < 1.0 K |
| **PSNR** | Peak signal-to-noise ratio, in dB | > 35 dB |
| **SSIM** | Structural similarity | > 0.95 |
| **MAE** | Mean absolute error, in K | < 0.8 K |
